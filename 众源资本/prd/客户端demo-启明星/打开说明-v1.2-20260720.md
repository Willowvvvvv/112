#### 角色怎么切

1. 点侧栏底部头像区 → **个人设置**（或侧栏「个人设置」）
2. **角色**：「客户经理 / 投资经理」↔「管理员」
3. 也可在 PE 模式个人设置里切角色（配置类菜单同步显隐）

侧栏脚会显示当前：`银行 · 客户经理` / `银行 · 管理员` 等。

#### 两边菜单差什么

| | 客户经理 / 投资经理 | 管理员 |
|--|-------------------|--------|
| 工作台 | 首页 · 客户 | 同左 |
| **授信配置** | 无 | 报告模版 · 材料类型 · **财务配置（与 PE 同页）** |
| **配置中心**（Cowork 精简） | 无 | 分析框架 · 风险规则 |
| **系统管理**（来自 Cowork Demo） | 无 | 用户与角色 · 数据源 · 操作日志 |
| 更多 | AML / 存量 / 设置 | + Pack 工具箱 |

（已去掉侧栏「项目」「演示入口」。`#bank:projects` 会跳到客户列表。）

客经直开配置 hash（如 `#bank:pack/tpl`）会被拦截并引导去个人设置。

#### 侧栏（客经默认）
- **首页 / 客户** 为主
- AML / 存量在「更多」；**无配置菜单、无项目菜单、无演示入口**
