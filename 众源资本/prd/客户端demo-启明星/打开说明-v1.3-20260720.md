### 报告任务工作区 · 点验

1. `#bank:capabilities` →「报告内容」下 **5 个 ready 卡**（尽调 / 财务 / 受益所有人 / 风险 / 初筛）均可：企业+材料表单 →「开始生成」→ 双栏任务工作区（左执行 · 右正文）
2. 工作区内点「定位报告正文」滚到右栏；生成中与草稿留在任务中心 / 工作区，**不**进我的报告
3. `#bank:tasks` 看过程待办；`#bank:artifacts` 只列已完成稿，行内 **打开 / 预览 / 导出**
4. 「贷后分析报告」灰态后续，点不动

OCR 顶栏：四角展开 icon → 全屏校对（再点 / Esc 退出）；侧栏折叠 icon → 收起/展开左侧一级菜单。
