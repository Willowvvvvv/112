**日期**: 2026-06-25  
**品牌**: 财跃启明星 · 一级市场 AI 尽调平台  
**交互**: 对话优先（类 ChatGPT / Claude）；进门即聊，项目延迟创建。

## 打开方式

```bash
cd /Users/ctt/project/finstep/新尽调宝
npm run dev
```

浏览器访问 http://127.0.0.1:8765/index.html

## 用户旅程

### A. 进门直接聊（默认）

1. 打开即进入**新对话**，无需选项目  
2. 直接输入，例如：`苏州博瑞生物医药风险怎么样`  
3. 助手在气泡内返回风险卡片  
4. 对话中出现「存为项目」条，一键存档（上传材料 / 写报告 / 导出前会提示）

### B. 从侧栏进已有项目

1. 侧栏「项目」展开 → 点「博瑞 Pre-B」  
2. 恢复项目上下文与 6 份材料  
3. 继续：整理材料 → 分析财报 → 写报告 → 确认 → 导出 Word

### C. 侧栏「最近」

- 「查博瑞公开风险」：演示无项目时的临时对话 + 存项目提示  
- 项目条目：进入长期存档会话

## 路由

| Hash | 含义 |
|------|------|
| `#/chat/new` | 新对话（默认首页） |
| `#/chat/:sessionId` | 临时会话 |
| `#/p/:projectId` | 已存项目 |

## 与 v1.1 差异

- 移除「项目列表墙」作为首页  
- 左侧窄栏：`+ 新对话`、**`+ 创建项目`**、最近 3 条、**默认展开**的全部项目列表  
- 临时对话顶栏提供 **「存为项目」**；对话内保留「存为项目」卡片  
- 无右侧栏、无阶段条、无完成度  
- 产出以聊天气泡内卡片呈现

## 项目入口（v1.2.1）

| 意图 | 入口 |
|------|------|
| 主动新建空项目 | 侧栏 **+ 创建项目** |
| 把当前对话存档 | 顶栏 **存为项目** / 对话内卡片 / 输入「存为项目」 |
| 进入已有项目 | 侧栏 **全部项目** 列表 |
